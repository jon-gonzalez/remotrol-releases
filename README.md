# Remotrol Mac

Versiones publicadas de **Remotrol Mac**, el agente de la barra de menús de macOS que recibe las órdenes de la app **Remotrol** del iPhone: teclas, dictado, botonera, trackpad y las peticiones de Claude Code.

Este repositorio solo contiene las versiones compiladas y el appcast de las actualizaciones automáticas. El código fuente no está aquí.

## Descargar

**[Descargar la última versión](https://github.com/jon-gonzalez/remotrol-releases/releases/latest/download/Remotrol-Mac.zip)** · [Todas las versiones](https://github.com/jon-gonzalez/remotrol-releases/releases)

1. Descomprime el zip y arrastra **Remotrol Mac** a la carpeta Aplicaciones.
2. Ábrela y sigue el asistente: permiso de Accesibilidad, vincular el iPhone con el código QR y, si usas Claude Code, conectarlo.

Requisitos: macOS 13 o posterior (Apple Silicon o Intel) y la app Remotrol en un iPhone de la misma red wifi.

La app está firmada con Developer ID y notarizada por Apple. Se actualiza sola (con [Sparkle](https://sparkle-project.org)); también desde el menú → «Buscar actualizaciones…».

# Remotrol Mac (English)

Published builds of **Remotrol Mac**, the macOS menu bar agent that receives commands from the **Remotrol** iPhone app: keys, dictation, button board, trackpad and Claude Code requests. This repository only holds the compiled releases and the automatic-update appcast; the source code isn't here.

**[Download the latest version](https://github.com/jon-gonzalez/remotrol-releases/releases/latest/download/Remotrol-Mac.zip)**. Unzip it, drag **Remotrol Mac** to Applications, open it and follow the assistant. Requires macOS 13 or later (Apple Silicon or Intel) and the Remotrol app on an iPhone on the same Wi-Fi network. Signed with Developer ID, notarized by Apple, and updated automatically with Sparkle.

Third-party licenses: Sparkle (MIT and its components' licenses) and the Silkscreen font (SIL OFL 1.1). Full texts are inside the app: Settings → About → “Third-party licenses”.
